# 需求池

流转：**待办 → 进行中 → 已完成**。不做了的移到 **搁置 / 不做**，写一句原因，不要直接删历史。

复制下面模板，贴到「待办」最上面。编号用 `B-年月日-序号`（当天第几条）。

---

## 如何追加

```markdown
### B-YYYYMMDD-N 短标题
- 提出：YYYY-MM-DD
- 优先级：高 / 中 / 低
- 说明：（要解决什么、给谁用）
- 验收：（怎样算做完）
```

开工时把整节剪到「进行中」，并注明目标版本（如 v0.2）。  
发布当天：整节剪到「已完成」，补上 `03-log.md` 锚点。
