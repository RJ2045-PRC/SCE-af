# 版本日志

## v0.2.1

从图纸 JSON 导出五份表。特殊特性清单同时写入气泡和特性表上的 SC/CC。

| 变更 | 用户侧结果 | 实现要点 |
| --- | --- | --- |
| 导出文档 | 核对后点「导出文档」得到 zip：检查作业标准、控制计划、检查清单、特殊特性清单、全尺寸 FAI | `sce_af/export_docs.py` 复制 `data/template` 填格 |
| 特殊特性清单 | 清单里既有尺寸 SC/CC，也有特性表里带 SC 或 CC 号的行 | `spec_rows` 先写有标识的特性，再写 SC/CC 气泡 |

## v0.1.0

脚手架：本机网页 + 源码 zip（复制本机 `.venv`）。第一条路径：气泡图切块识图，汇总 JSON。

| 变更 | 用户侧结果 | 实现要点 |
| --- | --- | --- |
| 本地网页 | 打开 `http://127.0.0.1:2054/` 可见版本号 | 标准库 HTTP；`/api/health` / `/api/version` |
| 切块识图 | 导入 PDF 后核对三块 JSON，可手改编号并下载 | 红框裁切；DeepSeek 只看小图；公差用 `limits.py` 解析 |
| 双系统 zip | Mac / Windows 各打带该机 `.venv` 的源码包 | `release/pack.py` |
